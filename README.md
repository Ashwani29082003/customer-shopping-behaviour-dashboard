# 🛍️ Customer Shopping Behavior Analysis

> An end-to-end Data Analytics project demonstrating the complete workflow from raw data to business insights using Python, SQL, Power BI.

---

## 📖 Overview

This project analyzes customer shopping behavior to identify purchasing patterns, customer preferences, and actionable business insights. It follows the complete Data Analytics lifecycle, including data loading, exploratory data analysis (EDA), data cleaning, SQL analysis and interactive dashboard development.

The objective of this project is to transform raw customer data into meaningful insights that support data-driven business decisions while demonstrating practical data analytics skills.

---

## 📂 Dataset

The dataset contains customer shopping information, including:

- Customer ID
- Age
- Gender
- Item Purchased
- Category
- Purchase Amount (USD)
- Payment Method
- Discount Applied
- Promo Code Used
- Subscription Status
- Shipping Type
- Review Rating
- Previous Purchases
- Season
- Frequency of Purchases
- Location

## 🚀 Project Workflow

### 1. Data Loading

- Imported the dataset
- Explored dataset structure
- Checked data types
- Generated descriptive statistics

### 2. Data Cleaning

- Removed duplicate records
- Handled missing values
- Corrected data types
- Standardized categorical values
- Prepared clean data for analysis

### 3. Exploratory Data Analysis (EDA)

Performed comprehensive analysis to understand:

- Customer demographics
- Purchase amount distribution
- Product category performance
- Payment method preferences
- Seasonal shopping trends
- Discount usage
- Subscription behavior
- Customer ratings
- Purchase frequency

Created visualizations to identify trends, patterns, and outliers.

### 4. SQL Analysis

Imported the cleaned dataset into a relational database (PostgreSQL, MySQL, or SQL Server) and performed SQL analysis using:

- SELECT Statements
- WHERE Clause
- ORDER BY
- Aggregate Functions
- GROUP BY
- HAVING
- CASE Statements
- Subqueries
- Window Functions
- Common Table Expressions (CTEs)

The SQL queries were designed to answer real-world business questions and generate meaningful insights.

### 5. Power BI Dashboard

Developed an interactive dashboard featuring:

- KPI Cards
- Total Revenue
- Average Purchase Value
- Sales by Category
- Customer Demographics
- Payment Method Analysis
- Seasonal Trends
- Discount Analysis
- Interactive Filters & Slicers

## ▶️ How to Run

### 1. Clone the Repository

```bash
git clone https://github.com/your-username/customer-shopping-behavior-analysis.git
```

### 2. Navigate to the Project

```bash
cd customer-shopping-behavior-analysis
```

### 3. Install Required Libraries

```bash
pip install -r requirements.txt
```

### 4. Run the Notebook

Open the Jupyter Notebook or Google Colab notebook and execute all cells.

### 5. SQL Analysis

- Import the cleaned dataset into PostgreSQL, MySQL, or SQL Server.
- Execute the SQL scripts available in the `sql/` directory.

### 6. Open the Dashboard

Open the `.pbix` file using **Power BI Desktop**.
